# 3. Deixar o tutor usar a IA

Na primeira vez que o tutor usa a IA, o VS Code mostra uma janela parecida com esta:

> **A extensão "Muri-Muri Socratico" quer usar os modelos de linguagem fornecidos pelo GitHub Copilot.**
>
> [ **Permitir** ]   [ Não permitir ]

👉 Clique em **Permitir** (*Allow*). Sem isso, o tutor não consegue responder.

O VS Code pergunta isso para proteger você: cada extensão precisa pedir antes de usar a IA da sua conta. Na janela também aparece o motivo do pedido.

## O que o tutor envia para a IA

Só quando você pede ajuda: a sua pergunta, o enunciado do exercício, o código do arquivo `.c` aberto, os erros do compilador e o resultado dos testes. Nada é enviado enquanto você só digita.

## Cliquei em "Não permitir". E agora?

O VS Code guarda a resposta e não pergunta de novo. Para liberar:

1. Clique em **Liberar a IA para o tutor** ao lado (ou no painel do tutor, no aviso vermelho).
2. Abre uma lista de extensões: **marque "Muri-Muri Socratico"** e clique em **OK**.

O mesmo caminho fica no **ícone de conta** 👤 (canto inferior esquerdo) → **Gerenciar acesso ao modelo de linguagem** (*Manage Language Model Access*).
