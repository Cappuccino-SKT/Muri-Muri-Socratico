# 2. Entrar no VS Code e ativar o Copilot

1. Clique no botão **Entrar com o GitHub** ao lado (ou no **ícone de conta** 👤, no canto inferior esquerdo do VS Code → *Entrar para usar o Copilot*).
2. O VS Code pergunta se pode abrir o navegador: clique em **Abrir** (*Open*).
3. No navegador, entre com o seu usuário e a sua senha do GitHub e clique em **Authorize Visual Studio Code**.
4. O navegador pergunta se pode abrir o VS Code: clique em **Abrir Visual Studio Code**.
5. De volta ao VS Code, o Copilot é ativado. Se você não tiver plano, ele já entra no **Copilot Free**.

## No computador da universidade

- Em muitos laboratórios, o VS Code "esquece" a conta quando o computador reinicia. Se o tutor parar de responder, entre de novo pelo ícone de conta 👤.
- **Ao terminar, saia da sua conta:** ícone de conta 👤 → seu usuário → **Sair** (*Sign Out*). Assim ninguém usa a sua conta depois de você.

## "Recursos de IA desativados"?

Se o VS Code disser que os recursos de IA estão desligados, abra **🩺 Tudo pronto?** no painel do tutor e clique em **Ligar os recursos de IA**. Se a opção estiver bloqueada, o computador foi configurado assim pela universidade: avise o professor.
