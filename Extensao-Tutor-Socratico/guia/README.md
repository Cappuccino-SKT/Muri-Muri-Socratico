# Guia de primeiros passos – Muri-Muri Socratico

Do zero até o tutor funcionando, para quem nunca usou o GitHub. Esse mesmo guia abre dentro do VS Code: no painel do tutor, clique em **📘 Guia passo a passo**, ou rode o comando **Tutor Socrático: Abrir o guia de primeiros passos**.

1. [Criar sua conta no GitHub](1-conta-github.md)
2. [Entrar no VS Code e ativar o Copilot](2-entrar-copilot.md)
3. [Deixar o tutor usar a IA](3-permissao.md)
4. [Escolher o modelo de IA](4-modelo.md)
5. [Confiar na pasta dos exercícios](5-pasta.md)
6. [Conferir o GCC](6-gcc.md)
7. [Usar o tutor](7-usar.md)

**Algo não funciona?** No painel do tutor, abra **🩺 Tudo pronto?**: ali aparece o que falta neste computador e o botão que resolve.
