# 4. Escolher o modelo de IA

O chat do VS Code deixa escolher qual modelo de IA responde. O tutor usa o modelo que estiver escolhido no chat.

1. Abra o chat (botão ao lado ou `Ctrl+Alt+I`).
2. Embaixo da caixa de mensagem há o **nome do modelo** (por exemplo, *Auto* ou *GPT-4.1*). Clique nele.
3. Escolha **Auto** ou um dos modelos sem custo extra.
4. Se o VS Code perguntar se quer **ativar** um modelo, clique em **Ativar** (*Enable*).

## Limites do plano gratuito

O **Copilot Free** tem um limite de mensagens por mês. Se o tutor disser que o limite foi atingido:

- espere a renovação do mês; ou
- peça o Copilot Pro grátis para estudantes pelo GitHub Education (veja o passo 1).

Dica: tente sozinho um pouco antes de cada pedido de ajuda. Além de aprender mais, você economiza mensagens.
