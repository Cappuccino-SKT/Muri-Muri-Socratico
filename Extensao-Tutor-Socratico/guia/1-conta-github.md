# 1. Criar sua conta no GitHub

A IA do tutor vem do **GitHub Copilot**. O plano **Copilot Free** é gratuito, mas precisa de uma conta no GitHub. Se você já tem conta, pule para o passo 2.

## Passo a passo

1. Acesse **[github.com/signup](https://github.com/signup)**.
2. Digite um **e-mail** que você acessa (pode ser o pessoal ou o da universidade) e clique em **Continue**.
3. Crie uma **senha** (pelo menos 15 caracteres, ou 8 com número e letra minúscula).
4. Escolha um **nome de usuário** (*username*). Ele aparece para outras pessoas, então prefira algo simples, como `maria-silva-utfpr`.
5. Resolva a verificação ("prove que você não é um robô").
6. Abra o seu e-mail: o GitHub manda um **código de 8 dígitos**. Digite o código na página.
7. Se perguntar sobre plano ou preferências, escolha o **gratuito (Free)** ou pule. Não é preciso cartão de crédito.

Pronto: a conta está criada. Guarde o nome de usuário e a senha, porque você vai usar nos computadores da universidade.

## Dica para estudantes (opcional)

Com o **GitHub Education** (Student Developer Pack), estudantes podem ter o **Copilot Pro** de graça, com mais uso por mês. O pedido é feito em [education.github.com](https://education.github.com/discount_requests/application), com o e-mail da universidade ou um comprovante de matrícula. A aprovação pode levar alguns dias.

**Não é preciso esperar:** o tutor funciona com o Copilot Free.
